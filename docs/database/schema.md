# Database Schema Overview

Tables:
- `users`: Migrant workers, caseworkers, admins
- `agencies`: Official SLBFE agency snapshots, licensing statuses, contact numbers
- `verifications`: Evidence-based job offer and agency verification records
- `documents`: Uploaded employment contracts, offer letters, screenshots
- `migration_journeys`: Active migration stages and scheduled safety check-ins
- `complaints`: Prepared complaint files and human caseworker review tracking
- `audit_logs`: Immutable logs of sensitive worker inquiries and data accesses
