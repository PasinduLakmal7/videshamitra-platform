# API Endpoints Specification

Prefix: `/api/v1`

- `/auth`: Registration, Login, Token Refresh
- `/chat`: LangGraph multi-agent conversational assistant
- `/verification`: Job offer & recruitment agency verification
- `/agencies`: SLBFE dated agency directory search & watchdog lookups
- `/documents`: Multi-page contract and job offer document uploads
- `/migration`: Worker journey stages (Day 7, 30, 90 check-ins)
- `/complaints`: Complaint filing, evidence compilation, LankaKonect drafting
- `/admin`: Caseworker case review, human escalation triage
